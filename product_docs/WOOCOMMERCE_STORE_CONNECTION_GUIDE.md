# 🔌 WooCommerce Store Connection — Step-by-Step Complete Guide
> **সহজ গাইড:** কীভাবে আপনার যেকোনো WooCommerce / WordPress ওয়েবসাইটকে ProfitPulse প্ল্যাটফর্মের সাথে ২ মিনিটে কানেক্ট করবেন এবং স্বয়ংক্রিয়ভাবে রিয়েল-টাইম অর্ডার ও প্রফিট ট্র্যাক করবেন।

---

## 📌 সংক্ষেপ ও কার্যপ্রণালী (How It Works)

ProfitPulse সরাসরি WooCommerce-এর অফিশিয়াল Webhook আর্কিটেকচার ব্যবহার করে। যখনই আপনার অনলাইন স্টোরে কোনো কাস্টমার অর্ডার প্লেস করবে:
1. WooCommerce সাথে সাথে ব্যাকগ্রাউন্ডে একটি সুরক্ষিত Webhook পে-লোড পাঠায়।
2. ProfitPulse স্বয়ংক্রিয়ভাবে অর্ডারটি ইনজেস্ট করে, কাস্টমারের তথ্য ও ঠিকানা সেভ করে।
3. প্রোডাক্টের COGS (ক্রয়মূল্য, প্যাকেজিং, ডেলিভারি ফি) মিলিয়ে রিয়েল-টাইম গ্রস ও নেট প্রফিট লক করে ফেলে।

---

## 🛠️ প্রয়োজনীয় পূর্বশর্ত (Prerequisites)

1. **একটি সক্রিয় WordPress সাইট** যেখানে WooCommerce প্লাগইন ইনস্টল ও অ্যাক্টিভ আছে (যেমন আপনার লাইভ ডোমেন অথবা টেস্ট করার জন্য TasteWP)।
2. **ProfitPulse একাউন্ট:** আপনার ড্যাশবোর্ডে লগইন করা থাকতে হবে।
3. **পাবলিক URL (যদি লোকাল মেশিনে টেস্ট করেন):**
   - লাইভ প্রোডাকশনে সরাসরি আপনার ডোমেন কাজ করবে (যেমন: `https://api.yourdomain.com`).
   - আপনার নিজের কম্পিউটারে (Localhost) টেস্ট করলে একটি ফ্রি টানেল চালু রাখবেন:
     ```bash
     npx localtunnel --port 8000
     ```
     *(টানেল চালু রাখলে আপনি একটি ফ্রি পাবলিক লিঙ্ক পাবেন, যেমন: `https://smart-ducks-bathe.loca.lt`)*

## 🚀 কানেক্ট করার সহজ ৪টি ধাপ

### ধাপ ১: ProfitPulse থেকে আপনার ডেডিকেটেড Webhook URL সংগ্রহ করুন

1. **ProfitPulse ড্যাশবোর্ডে** যান: `http://localhost:3000/orders` (বা আপনার লাইভ অ্যাপ ডোমেন)।
2. উপরে থাকা **"Connect Store / Webhook"** বাটনে ক্লিক করুন।
3. পপআপ উইন্ডো থেকে **"WooCommerce"** ট্যাব সিলেক্ট করুন।
4. **"আপনার ডেডিকেটেড WEBHOOK DELIVERY URL"** বক্সে থাকা লিঙ্কটি **Copy URL** বাটনে ক্লিক করে কপি করে নিন।

> **URL ফরম্যাটটি সাধারণত এমন দেখায়:**  
> `https://<YOUR-DOMAIN>/api/v1/orders/webhook/woocommerce?tenant_id=<YOUR-TENANT-ID>`

---

### ধাপ ২: WordPress অ্যাডমিনে Webhook সেটআপ করুন

1. আপনার WordPress অ্যাডমিন প্যানেলে লগইন করুন:  
   👉 `https://your-store.com/wp-admin`
2. বাম পাশের মেনু থেকে ক্রমানুসারে যান:  
   👉 **WooCommerce** ➔ **Settings** (সেটিংস) ➔ উপরে থাকা **Advanced** ট্যাবে ক্লিক করুন।
3. সাব-মেনু থেকে **"Webhooks"** লিঙ্কে ক্লিক করুন।
4. উপরে থাকা **"Add webhook"** বাটনে ক্লিক করুন।

#### 📝 Webhook Data ফিল্ডগুলো হুবহু নিচের মতো পূরণ করুন:

| ফিল্ডের নাম (Field) | কী নির্বাচন/লিখবেন (Value) | বিবরণ |
| :--- | :--- | :--- |
| **Name** | `ProfitPulse Ingestion` | চেনার সুবিধার জন্য যেকোনো নাম দিতে পারেন |
| **Status** | **`Active`** | অবশ্যই **Active** রাখতে হবে |
| **Topic** | **`Order created`** | নতুন অর্ডার আসলেই ডেটা পাঠাবে |
| **Delivery URL** | *ধাপ ১ থেকে কপি করা লিঙ্কটি পেস্ট করুন* | উদাহরণ: `https://.../api/v1/orders/webhook/woocommerce?tenant_id=...` |
| **Secret** | *খালি রাখুন বা যেকোনো টেক্সট দিন* | ঐচ্ছিক সিক্রেট কি |
| **API Version** | **`WP REST API Integration v3`** | আধুনিক WooCommerce REST API v3 |

5. নিচে থাকা নীল রঙের **"Save webhook"** বাটনে ক্লিক করুন!

> 🟢 **সফলতার লক্ষণ:**  
> পেজের উপরে একটি সবুজ নোটিফিকেশন আসবে:  
> **"Webhook updated successfully."**  
> *(এর মানে আপনার সাইটের সাথে ProfitPulse-এর হ্যান্ডশেক ১০০% সফল হয়েছে)*

### ধাপ ৩: কাস্টমার হিসেবে একটি লাইভ টেস্ট অর্ডার প্লেস করুন

কানেকশন পুরোপুরি সচল কিনা তা পরীক্ষা করতে একটি লাইভ টেস্ট অর্ডার করুন:

1. আপনার স্টোরের শপ পেজে যান: `https://your-store.com/shop`
2. যেকোনো একটি প্রোডাক্ট **"Add to cart"** করুন এবং **Checkout** পেজে যান।
3. কাস্টমার ইনফরমেশন পূরণ করুন:
   - নাম (Name): যেমন `Rahim Uddin`
   - মোবাইল নম্বর (Phone): যেমন `01712345678`
   - ঠিকানা (Address): যেমন `Dhanmondi, Dhaka`
4. পেমেন্ট অপশন হিসেবে **Cash on delivery (COD)** সিলেক্ট করুন।
5. **"Place order"** বাটনে ক্লিক করে অর্ডারটি কনফার্ম করুন।

---

### ধাপ ৪: ProfitPulse ড্যাশবোর্ডে লাইভ রেজাল্ট দেখুন

অর্ডার কনফার্ম করার সাথে সাথেই ProfitPulse ড্যাশবোর্ডে চলে আসুন:  
👉 **`http://localhost:3000/orders`**

আপনি দেখতে পাবেন:
* 🟣 অর্ডারের পাশে একটি স্পষ্ট বেগুনি ব্যাজ এসেছে: **`WOOCOMMERCE`**।
* 👤 কাস্টমারের নাম, ফোন নম্বর ও ডেলিভারি ঠিকানা হুবহু সিঙ্ক হয়ে গেছে।
* 💵 মোট সেলস ভ্যালু ও প্রফিট মার্জিন স্বয়ংক্রিয়ভাবে ক্যালকুলেট হয়ে গেছে।
* 📦 অর্ডারটির স্ট্যাটাস **`PENDING`** হিসেবে প্রস্তুত (কনফার্মেশন কল ট্র্যাকিংয়ের জন্য)।

## ❓ সাধারণ সমস্যা ও সমাধান (Troubleshooting)

### ১. সেভ করার সময় `Error: Delivery URL cannot be reached` দেখালে:
* **কারণ:** আপনি যদি Delivery URL-এ `http://localhost:8000` বা `127.0.0.1` ব্যবহার করেন, তবে রিমোট ক্লাউড WordPress সার্ভার আপনার লোকাল পিসি খুঁজে পায় না।
* **সমাধান:** লোকালহোস্ট টেস্টের জন্য অবশ্যই **Localtunnel** (`npx localtunnel --port 8000`) বা **Ngrok** দিয়ে পাওয়া পাবলিক HTTPS লিঙ্ক ব্যবহার করবেন।

### ২. `Error: Delivery URL returned response code: 400` দেখালে:
* **কারণ:** পূর্বের কোনো আউটডেটেড ব্যাকএন্ড চালু থাকলে বা URL-এ টাইপো থাকলে।
* **সমাধান:** Delivery URL-এর শেষে কোনো অতিরিক্ত স্পেস আছে কিনা চেক করুন। নিশ্চিত করুন যে ব্যাকএন্ড সার্ভার চালু রয়েছে এবং সঠিক `tenant_id` কোয়েরি প্যারামিটার যুক্ত আছে।

### ৩. অর্ডার ডুপ্লিকেট হওয়ার ভয় আছে কি?
* **না!** ProfitPulse-এ বিল্ট-ইন **Idempotency Protection** রয়েছে।同一个 অর্ডার WooCommerce থেকে ভুলবশত একাধিকবার সেন্ড হলেও সিস্টেমে কখনোই ডুপ্লিকেট অর্ডার ঢুকবে না।
